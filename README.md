# Garnet habits

A wireframe garnet crystal, white (or species-colored) on black, whose habit
slider continuously sweeps the real crystallographic form space:
d{110} -> d+n -> n{211} -> n+h -> {321}.

Open `index.html` in a browser, or `npm start` and visit localhost:8080.
Run `npm test` for the geometry verification suite. See CLAUDE.md for
architecture and invariants.
